# ADAS Dashboard

Streamlit dashboard for the ADAS Performance Investigation & Re-simulation Framework.

## Run

```bash
pip install streamlit pandas numpy plotly
streamlit run dashboard/app.py
```

Upload the telemetry CSV generated by the existing project.

## Expected data

The app expects the project's core telemetry fields, including:

- scenario_id
- timestamp
- vehicle_speed_kmh
- pedestrian_distance_m
- relative_closing_speed_ms
- ttc_seconds
- ground_truth_warning_required
- ground_truth_braking_required
- pedestrian_detected
- detection_confidence
- warning_triggered
- brake_triggered

It intentionally treats "not exercised" separately from an exercised failure.

FCW TTC threshold: 2.5 s  
AEB TTC threshold: 1.5 s  
Telemetry: 10 Hz

These are synthetic project assumptions, not Toyota, UNECE, Euro NCAP, or regulatory thresholds.
